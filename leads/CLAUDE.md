# Leads folder rules

These rules apply to this folder only.

- Everyone in `leads.csv` is a made-up practice person. None of them are real.
- Never add real people or real email addresses to this folder.
- Every row needs a value in the `consent` column. Never leave it empty.
- Never change the `@example.com` email addresses. That domain is reserved and can never receive mail, so no real person is ever emailed.
